# Littlemoon

Personal AI engineering notes site built with Next.js static export for GitHub Pages.

Live site: https://littlemoon-zh.github.io

## Local development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

The build generates SEO metadata, exports static files into `out/`, copies hosted HTML sites into `out/notes/<slug>/`, and deploys through GitHub Actions.

## Quality checks

```bash
npm run lint
npm audit --omit=dev
```

## Content model

- `content/notes/*.mdx` for long-form notes
- `content/sites/<slug>/index.html` for standalone hosted HTML articles
- `content/sites/<slug>/site.json` for hosted HTML article metadata
- `content/demos/*.mdx` for prototype writeups
- `public/sitemap.xml`, `public/feed.xml`, and `public/robots.txt` are generated by `npm run metadata`

## Frontmatter schema

Note:

```md
---
title: Post title
date: 2026-02-28
summary: Short summary for list pages
tags: transformer, attention
layout: article
draft: false
---
```

Hosted artifact note:

```md
---
title: Interactive report title
date: 2026-07-02
summary: Short summary for list pages
tags: research, dataviz
layout: artifact
artifact: registered-component-id
artifactChrome: immersive
draft: false
---
```

Artifact notes use the same `/notes/yyyy-mm-dd-title` URL pattern, but render inside a standalone hosted page shell. `artifactChrome` can be:

- `browser`: shared hosted shell with browser-like frame
- `immersive`: shared top bar, artifact controls the main page layout
- `custom`: artifact component controls the whole page surface

Hosted HTML site metadata:

```json
{
  "title": "Standalone HTML article title",
  "date": "2026-07-02",
  "summary": "Short summary for list pages.",
  "tags": ["hosted-html", "notes"],
  "draft": false,
  "chrome": "site"
}
```

Hosted HTML sites publish at `/notes/<slug>/`. `chrome` can be:

- `site`: inject the Littlemoon topbar during build
- `none`: publish the HTML exactly as authored

Demo:

```md
---
title: Demo title
date: 2026-02-28
summary: Short summary for list pages
stack: nextjs, typescript
liveUrl:
repoUrl:
draft: false
---
```

`draft: true` entries are hidden in production builds.

## Markdown rendering

Rendering uses a standard pipeline:

- `gray-matter` for frontmatter
- `zod` for schema validation
- `remark/rehype` for Markdown + GFM + math
- `rehype-pretty-code` for syntax highlighting

## Create new content

```bash
npm run new:note -- --slug your-note-slug
npm run new:demo -- --slug your-demo-slug
npm run new:site -- --slug your-html-site-slug
```

Create a hosted artifact note:

```bash
npm run new:note -- --slug yyyy-mm-dd-title --layout artifact --artifact component-id --artifact-chrome immersive
```

Optional title:

```bash
npm run new:note -- --slug your-note-slug --title "Custom title"
npm run new:site -- --slug your-html-site-slug --title "Custom title"
```

Use `npm run build` and preview `out/` to test hosted HTML sites locally. `next dev` lists hosted HTML entries, but standalone HTML files are copied only by the production build.

## Routes

- `/` home
- `/notes` and `/notes/[slug]` for MDX notes and React artifacts
- `/notes/<slug>/` for hosted HTML sites
- `/demos` and `/demos/[slug]`
